# 隱私權聲明

生效日期：2026-11-23。

本聲明適用於所有 Nabi 網站：nabi-lang.org、docs.nabi-lang.org、packages.nabi-lang.org、playground.nabi-lang.org、dist.nabi-lang.org 與 nabi.sh。它說明每個網站保存哪些關於您的資料、為何保存、保存多久，以及如何與我們聯絡。

## 我們是誰

這些網站由 **DaminStudio**（「我們」）營運，DaminStudio 是本聲明所述個人資料的控管者。關於本聲明中的任何事項，請寫信至 [privacy@nabi-lang.org](mailto:privacy@nabi-lang.org)。

伺服器執行於美國的 Amazon Web Services，Amazon Web Services 為我們的處理者。

## 瀏覽網站

您不需要帳戶即可瀏覽所有網站。我們不設定任何追蹤或廣告 Cookie。

- **Cloudflare** 作為我們的處理者，承載前往這些網站的所有流量。它會看到您的 IP 位址與請求，用來阻擋攻擊與執行速率限制，並以 Cloudflare Web Analytics 計算頁面瀏覽次數；該服務不設定 Cookie、不使用裝置指紋，也不會跨網站追蹤您。
- **伺服器日誌**記錄每個請求的方法、網址與狀態，不記錄您的 IP 位址，最多保留 30 天後刪除。
- **您的選擇保留在您的瀏覽器中**。您選擇的佈景主題存放在適用於 nabi-lang.org 及其子網域的 `theme` Cookie 中；不會傳送給我們。文件不會記住其他任何內容；Playground 將您的程式碼保存在瀏覽器的本機儲存空間中。

## 套件登錄庫

您以 GitHub 登入 packages.nabi-lang.org。登錄庫只接受已啟用雙重驗證的 GitHub 帳戶登入：是否啟用由 GitHub 告知我們，我們不會保存這項資訊。我們會保存：

- **您的 GitHub 帳戶**：您的數字 ID、登入名稱、顯示名稱與大頭貼網址（依 GitHub 提供的內容，每次登入時更新），以及 GitHub 提供給我們的電子郵件地址，用於寄送與您的套件及帳戶相關的通知。
- **您的工作階段**：讓您維持登入狀態最長 30 天的 Cookie，以及每個工作階段的開始時間、最後使用時間與登入時所用瀏覽器及作業系統的名稱，讓您能在帳戶頁面上查看並結束工作階段。
- **發布權杖**，僅以雜湊值的形式儲存。
- **您身為發布者的操作**：您發布、撤回、取消撤回或刪除的版本及其時間，您新增或移除的擁有者與受信任的發布者，您建立或撤銷的權杖，以及您起草或發布的安全性公告。您對某個套件的操作是該套件公開紀錄的一部分，並顯示在該套件的頁面上；其餘操作只顯示在您的帳戶頁面上。
- **內容管理紀錄**，於我們對某個帳戶或套件採取措施時產生。

頁面與 API 會在您發布的內容旁顯示您的登入名稱、顯示名稱與大頭貼。GitHub 會得知您已登入。通知由 Amazon Simple Email Service 作為我們的處理者，從 noreply@nabi-lang.org 寄出；您可以在帳戶頁面上關閉全部通知，或依類型逐一關閉。

## Playground

- **您執行的程式碼**會傳送到伺服器，在沒有網路的隔離沙箱中編譯並執行。您正在編輯的程式碼也會傳送，以便在輸入時進行檢查。原始碼在工作結束時刪除；編譯後的程式依其內容快取，快取滿時從最舊的開始刪除。
- **您分享的程式碼**以其連結儲存，且為**公開且永久**：任何持有連結的人都能閱讀。請勿分享機密資訊。若要移除已分享的連結，請寫信至 [privacy@nabi-lang.org](mailto:privacy@nabi-lang.org)。

## 位址與速率限制

伺服器僅在記憶體中保存您的 IP 位址約一分鐘，用於限制一個用戶端可以傳送的請求數量。

## 我們為何保存這些資料

- 為了營運網站並維護其安全（我們在提供與保護一項公共服務上的正當利益）。
- 為了營運您的登錄庫帳戶以及您發布的套件，這是您登入時所提出的要求（履行契約）。

## 保存多久

- 登錄庫帳戶在登錄庫營運期間持續保留，或保留至您要求我們刪除為止。您所發布內容的紀錄會隨套件一同保留，因為其他人的程式相依於這些套件；刪除帳戶後，紀錄只會顯示您的 GitHub ID 與登入名稱。
- 工作階段在您登出、在帳戶頁面上結束它，或登入 30 天後結束。
- 已分享的 Playground 程式碼保留至依要求移除為止。
- 登錄庫的資料與已分享的 Playground 程式碼每晚備份到位於美國另一個區域的 Amazon S3，伺服器磁碟也會建立快照；備份與快照最多保留 90 天。伺服器日誌不會備份。

## 您的權利

您可以詢問我們保存了哪些關於您的資料、要求我們更正或刪除這些資料、反對我們使用這些資料的方式，或索取一份副本。請寫信至 [privacy@nabi-lang.org](mailto:privacy@nabi-lang.org)；我們會在 30 天內回覆。您也可以向您所在地的資料保護主管機關提出申訴。

## 變更

本聲明有所變更時，我們會在本頁說明變更的時間與內容。

# 隱私權聲明

> [!NOTE]
> **草稿**。本文尚未經律師審閱，內容可能變動。

本聲明適用於所有 Nabi 網站：nabi-lang.org、docs.nabi-lang.org、packages.nabi-lang.org、playground.nabi-lang.org 與 nabi.sh。它說明每個網站保存哪些關於您的資料、為何保存、保存多久，以及如何與我們聯絡。

## 我們是誰

這些網站由 **DaminStudio**（「我們」）營運。關於本聲明中的任何事項，請寫信至 [privacy@nabi-lang.org](mailto:privacy@nabi-lang.org)。

## 瀏覽網站

您不需要帳戶即可瀏覽所有網站。我們不設定任何追蹤或廣告 Cookie。

- **Cloudflare** 作為我們的處理者，承載前往這些網站的所有流量。它會看到您的 IP 位址與請求，並以 Cloudflare Web Analytics 計算頁面瀏覽次數；該服務不使用 Cookie，也不使用裝置指紋。
- **伺服器日誌**記錄請求路徑與狀態，不記錄您的 IP 位址。
- **您的選擇保留在您的瀏覽器中**。您選擇的佈景主題存放在適用於 nabi-lang.org 及其子網域的 `theme` Cookie 中；不會傳送給我們。文件不會記住其他任何內容；Playground 將您的程式碼保存在瀏覽器的本機儲存空間中。

## 套件登錄庫

當您以 GitHub 登入 packages.nabi-lang.org 時，我們會保存：

- **您的 GitHub 帳戶**：您的數字 ID、登入名稱、顯示名稱與大頭貼網址（以 GitHub 提供者為準，每次登入時更新），以及 GitHub 提供給我們的電子郵件地址，用於寄送與您的套件及帳戶相關的通知。
- **工作階段**，以 Cookie 的形式讓您維持登入狀態。它僅用於登入。
- **發布權杖**，僅以雜湊值的形式儲存。
- **您身為發布者的操作**：您發布、撤回或取消撤回的版本及其時間，以及您新增的擁有者與受信任的發布者。這是每個套件公開紀錄的一部分，並顯示在該套件的頁面上。
- **內容管理紀錄**，於我們對某個帳戶或套件採取措施時產生。

頁面與 API 會在您發布的內容旁顯示您的登入名稱、顯示名稱與大頭貼。GitHub 會得知您已登入。通知透過 Amazon Web Services（Amazon SES）寄送，其作為我們的處理者。

## Playground

- **您執行的程式碼**會傳送到伺服器，在隔離的沙箱中編譯並執行。編譯後的程式依其內容快取一段時間後刪除。
- **您分享的程式碼**以其連結儲存，且為**公開且永久**：任何持有連結的人都能閱讀。請勿分享機密資訊。若要移除已分享的連結，請寫信至 [privacy@nabi-lang.org](mailto:privacy@nabi-lang.org)。

## 位址與速率限制

伺服器僅在記憶體中保存您的 IP 位址約一分鐘，用於限制一個用戶端可以傳送的請求數量。

## 我們為何保存這些資料

- 為了營運網站並維護其安全（我們在提供與保護一項公共服務上的正當利益）。
- 為了營運您的登錄庫帳戶以及您發布的套件，這是您登入時所提出的要求（履行契約）。

## 保存多久

- 登錄庫帳戶在登錄庫營運期間持續保留，或保留至您要求我們刪除為止。您所發布內容的紀錄會隨套件一同保留，因為其他人相依於它；刪除帳戶後，紀錄只會顯示您的 GitHub ID 與登入名稱。
- 已分享的 Playground 程式碼保留至依要求移除為止。
- 上述資料的備份最多保留 30 天。

## 您的權利

您可以詢問我們保存了哪些關於您的資料、要求我們更正或刪除這些資料、反對我們使用這些資料的方式，或索取一份副本。請寫信至 [privacy@nabi-lang.org](mailto:privacy@nabi-lang.org)；我們會在 30 天內回覆。您也可以向您所在地的資料保護主管機關提出申訴。

## 變更

本聲明有所變更時，我們會在本頁說明變更的時間與內容。

# Nabi 0.1.8: `units` 0.1.2 bundled

<!-- date: 2026-11-28 -->

<div class="lead-sm">Nabi 0.1.8 bundles the <code>units</code> package 0.1.2, which converts with <code>-></code>. Update with <code>nabi toolchain update</code>, or install again from the <a href="../download.html">download page</a>.</div>

With the bundled `units`, `5km -> mi` and `f"{bag -> lb:.2}"` work with no download, and the playground's units example uses `->` too. In the playground, the code inside an f-string's braces is now highlighted as code.

The full list of changes is in the [release notes](https://github.com/nabi-lang/nabi/releases/tag/v0.1.8).

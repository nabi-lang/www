# 隐私声明

> [!NOTE]
> **草稿**。本文尚未经过律师审阅，可能会有变动。

本声明适用于所有 Nabi 网站：nabi-lang.org、docs.nabi-lang.org、packages.nabi-lang.org、playground.nabi-lang.org 和 nabi.sh。它说明每个网站保存哪些关于您的信息、为什么保存、保存多久，以及如何联系我们。

## 我们是谁

这些网站由 **DaminStudio**（“我们”）运营。关于本声明中的任何事项，请写信至 [privacy@nabi-lang.org](mailto:privacy@nabi-lang.org)。

## 浏览网站

您无需账户即可浏览所有网站。我们不设置任何跟踪或广告 Cookie。

- **Cloudflare** 作为我们的处理者，承载访问这些网站的全部流量。它能看到您的 IP 地址和请求，并通过 Cloudflare Web Analytics 统计页面浏览量；该服务不使用 Cookie，也不使用设备指纹。
- **服务器日志**记录请求路径和状态码，不记录您的 IP 地址。
- **您的选择保留在您的浏览器中**。您选择的主题保存在适用于 nabi-lang.org 及其子域名的 `theme` Cookie 中；不会发送给我们。文档不记住其他任何内容；Playground 把您的代码保存在浏览器的本地存储中。

## 包注册表

当您使用 GitHub 登录 packages.nabi-lang.org 时，我们保存：

- **您的 GitHub 账户**：您的数字 ID、登录名、显示名称和头像地址（以 GitHub 提供的为准，每次登录时更新），以及 GitHub 提供给我们的电子邮件地址，用于向您发送关于您的包和账户的通知。
- **会话**，以 Cookie 的形式让您保持登录状态。它仅用于登录。
- **发布令牌**，仅以哈希值的形式存储。
- **您作为发布者的操作**：您发布、撤回或取消撤回的版本及其时间，以及您添加的所有者和可信发布者。这是每个包公开记录的一部分，显示在包的页面上。
- **内容管理记录**，在我们对某个账户或包采取措施时产生。

页面和 API 会在您发布的内容旁显示您的登录名、显示名称和头像。GitHub 会知道您进行了登录。通知通过 Amazon Web Services（Amazon SES）发送，其作为我们的处理者。

## Playground

- **您运行的代码**会被发送到服务器，在隔离的沙箱中编译并运行。编译后的程序按其内容缓存一段时间，然后删除。
- **您分享的代码**以其链接存储，并且是**公开且永久的**：任何拥有链接的人都可以阅读。不要分享机密信息。如需删除已分享的链接，请写信至 [privacy@nabi-lang.org](mailto:privacy@nabi-lang.org)。

## 地址与速率限制

服务器仅在内存中保存您的 IP 地址约一分钟，用于限制一个客户端可以发送的请求数量。

## 我们为什么保存这些信息

- 为了运营网站并保障其安全（我们在提供和保护一项公共服务方面的正当利益）。
- 为了运营您的注册表账户以及您发布的包，这是您在登录时提出的请求（履行合同）。

## 保存多久

- 注册表账户在注册表运营期间一直保留，或保留到您要求我们删除为止。您发布内容的记录随包一起保留，因为其他人依赖于它；删除账户后，记录只显示您的 GitHub ID 和登录名。
- 已分享的 Playground 代码保留到应请求删除为止。
- 上述数据的备份最多保留 30 天。

## 您的权利

您可以询问我们保存了哪些关于您的信息，要求我们更正或删除这些信息，反对我们使用这些信息的方式，或索取一份副本。请写信至 [privacy@nabi-lang.org](mailto:privacy@nabi-lang.org)；我们会在 30 天内答复。您也可以向您所在地的数据保护机构投诉。

## 变更

本声明发生变更时，我们会在本页说明变更的时间和内容。

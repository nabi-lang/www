# 隐私声明

生效日期：2026-11-23。

本声明适用于所有 Nabi 网站：nabi-lang.org、docs.nabi-lang.org、packages.nabi-lang.org、playground.nabi-lang.org、dist.nabi-lang.org 和 nabi.sh。它说明每个网站保存哪些关于您的信息、为什么保存、保存多久，以及如何联系我们。

## 我们是谁

这些网站由 **DaminStudio**（“我们”）运营，DaminStudio 是本声明所述个人信息的控制者。关于本声明中的任何事项，请写信至 [privacy@nabi-lang.org](mailto:privacy@nabi-lang.org)。

服务器运行在位于美国的 Amazon Web Services 上，由其作为我们的处理者。

## 浏览网站

您无需账户即可浏览所有网站。我们不设置任何跟踪或广告 Cookie。

- **Cloudflare** 作为我们的处理者，承载访问这些网站的全部流量。它能看到您的 IP 地址和请求，用它们来拦截攻击和执行速率限制，并通过 Cloudflare Web Analytics 统计页面浏览量；该服务不设置 Cookie，不使用设备指纹，也不跨网站跟踪您。
- **服务器日志**记录每个请求的方法、地址和状态码，不记录您的 IP 地址，最多保留 30 天后删除。
- **您的选择保留在您的浏览器中**。您选择的主题保存在适用于 nabi-lang.org 及其子域名的 `theme` Cookie 中；不会发送给我们。文档不记住其他任何内容；Playground 把您的代码保存在浏览器的本地存储中。

## 包注册表

您使用 GitHub 登录 packages.nabi-lang.org。注册表只接受已开启双重身份验证的 GitHub 账户登录：是否开启由 GitHub 告知我们，我们不保存这一信息。我们保存：

- **您的 GitHub 账户**：您的数字 ID、登录名、显示名称和头像地址（以 GitHub 提供的为准，每次登录时更新），以及 GitHub 提供给我们的电子邮件地址，用于向您发送关于您的包和账户的通知。
- **您的会话**：让您保持登录状态最长 30 天的 Cookie，以及每个会话的开始时间、最后使用时间和登录时所用浏览器与操作系统的名称，以便您在账户页面上查看和结束会话。
- **发布令牌**，仅以哈希值的形式存储。
- **您作为发布者的操作**：您发布、撤回、取消撤回或删除的版本及其时间，您添加或移除的所有者和可信发布者，您创建或吊销的令牌，以及您起草或发布的安全公告。您对某个包的操作是该包公开记录的一部分，显示在包的页面上；其余操作只显示在您的账户页面上。
- **内容管理记录**，在我们对某个账户或包采取措施时产生。

页面和 API 会在您发布的内容旁显示您的登录名、显示名称和头像。GitHub 会知道您进行了登录。通知由 Amazon Simple Email Service 作为我们的处理者，从 noreply@nabi-lang.org 发出；您可以在账户页面上关闭全部通知，或按类型逐一关闭。

## Playground

- **您运行的代码**会被发送到服务器，在没有网络的隔离沙箱中编译并运行。您正在编辑的代码也会被发送，以便在输入时进行检查。源代码在任务结束时删除；编译后的程序按其内容缓存，缓存满时从最旧的开始删除。
- **您分享的代码**以其链接存储，并且是**公开且永久的**：任何拥有链接的人都可以阅读。不要分享机密信息。如需删除已分享的链接，请写信至 [privacy@nabi-lang.org](mailto:privacy@nabi-lang.org)。

## 地址与速率限制

服务器仅在内存中保存您的 IP 地址约一分钟，用于限制一个客户端可以发送的请求数量。

## 我们为什么保存这些信息

- 为了运营网站并保障其安全（我们在提供和保护一项公共服务方面的正当利益）。
- 为了运营您的注册表账户以及您发布的包，这是您在登录时提出的请求（履行合同）。

## 保存多久

- 注册表账户在注册表运营期间一直保留，或保留到您要求我们删除为止。您发布内容的记录随包一起保留，因为其他人依赖于它；删除账户后，记录只显示您的 GitHub ID 和登录名。
- 会话在您退出登录、在账户页面上结束它，或登录 30 天后结束。
- 已分享的 Playground 代码保留到应请求删除为止。
- 注册表的数据和已分享的 Playground 代码每晚备份到位于美国另一区域的 Amazon S3，服务器磁盘也会创建快照；备份和快照最多保留 90 天。服务器日志不做备份。

## 您的权利

您可以询问我们保存了哪些关于您的信息，要求我们更正或删除这些信息，反对我们使用这些信息的方式，或索取一份副本。请写信至 [privacy@nabi-lang.org](mailto:privacy@nabi-lang.org)；我们会在 30 天内答复。您也可以向您所在地的数据保护机构投诉。

## 变更

本声明发生变更时，我们会在本页说明变更的时间和内容。

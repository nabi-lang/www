# 使用条款

生效日期：2026-11-23。

本条款适用于所有 Nabi 网站：nabi-lang.org、docs.nabi-lang.org、packages.nabi-lang.org、playground.nabi-lang.org、dist.nabi-lang.org 和 nabi.sh，这些网站由 **DaminStudio**（“我们”）运营。使用任一网站即表示您同意本条款。

## 网站与工具链

文档和工具链是开源的；适用于它们的是各自的许可证（代码为 MIT 或 Apache-2.0，语言规范文本为 CC BY 4.0），而非本条款。本条款涵盖的是将这些网站作为服务来使用。

## 包注册表

- 您只能发布您有权发布的代码，并采用您在其中声明的许可证。您保留对代码的权利；发布即授予我们和所有人在注册表运营期间存储、复制该代码并将其提供给注册表用户的权利。
- 在发布某个版本后的 72 小时内，且没有其他包依赖它时，您可以删除该版本；该版本号此后不能再使用。超过这个期限，版本就是永久的：您可以撤回它，但不能删除它，以便依赖它的构建能够继续工作。对于违反[包使用政策](https://packages.nabi-lang.org/policy)或法律的版本或账户，我们可以将其移除。
- 登录需要已开启双重身份验证的 GitHub 账户。请妥善保管您的账户和令牌。使用它们发布的内容由您负责。

## Playground

- 用它来试用 Nabi。不要用它攻击他人、挖矿、向外发送流量（它没有网络连接），或运行任何违法的内容。
- 分享的代码是公开且永久的。如需删除链接，请写信至 [privacy@nabi-lang.org](mailto:privacy@nabi-lang.org)。
- 我们可以限制每个客户端可运行的任务量，并终止占用资源过多的任务。

## 合理使用

不要使网站过载、规避其限制，或以降低他人使用体验的方式抓取网站内容。在速率限制范围内自动化使用注册表的 API 是允许的。

## 无担保

网站按“现状”提供，不附带任何形式的担保。我们会努力保持网站的正常运行和内容正确，但不保证网站始终可用，也不保证其提供的内容没有错误。注册表中的代码属于其作者，而非我们；请审查您所依赖的代码。

## 责任

在法律允许的范围内，对于因使用网站或网站所提供的代码而产生的任何损失，我们不承担责任。

## 变更

本条款发生变更时，我们会在本页说明变更的时间和内容。如有疑问，请发送至 [contact@nabi-lang.org](mailto:contact@nabi-lang.org)。
